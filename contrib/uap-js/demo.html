UAP mint/transfer demo

Demo only, not production-ready key handling. Keys here are generated in-browser and kept only in page memory — they are never sent anywhere. But this page does not persist keys, has no backup/recovery, and should not be used with real funds. It also builds and signs transactions locally and shows you the resulting hex; it does not broadcast anything on its own (see "Broadcasting" below).

1. Generate a keypair
2. Build an OP_MINT output script

Give this script's hex to whoever is funding the mint: it becomes output 0's scriptPubKey in a transaction spending a UTXO worth ≥ 1000 coin (the OP_MINT entry fee), in place of a normal address. See doc/uap-minting-guide.md for the raw transaction construction steps -- that part still goes through your node's wallet as usual, since it's an ordinary funding input, not a UAP spend.

3. Sign a transfer spend

Once a mint (or an earlier transfer) is confirmed, spend it here.

Broadcasting

This page never talks to a node directly -- browsers should not be pointed at raw node RPC (no CORS, and it's a trusted-operator interface, not a public API). To actually submit the hex above, send it to a backend you control that calls sendrawtransaction, or paste it into whippet-cli sendrawtransaction <hex> yourself. Query uap-indexer's /positions?pubkey=... endpoint to find UTXOs to spend.
